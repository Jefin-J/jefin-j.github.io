# Jefin Jacob — Portfolio

A small Flutter web portfolio. Edit the text and lists near the top of
`lib/main.dart` to update the site.

## Run locally

This project targets Flutter 3.35.7. From the project folder run:

```sh
flutter pub get
flutter run -d chrome
```

## Deploy

The GitHub Actions workflow builds with Flutter 3.35.7 and deploys to GitHub
Pages whenever changes are pushed to `main`. In **Settings → Pages**, set the
source to **GitHub Actions**.
