# Jefin Jacob — Portfolio

A personal portfolio built with Flutter for the web and deployed to GitHub Pages.

## Run locally

Install the [Flutter SDK](https://docs.flutter.dev/get-started/install), then run:

```sh
flutter pub get
flutter run -d chrome
```

## Deploy

The GitHub Actions workflow builds and deploys the site to GitHub Pages whenever
changes are pushed to `main`. In the repository's **Settings → Pages**, set the
build and deployment source to **GitHub Actions**.
